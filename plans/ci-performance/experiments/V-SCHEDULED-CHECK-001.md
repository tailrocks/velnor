# V-SCHEDULED-CHECK-001: strict lock fixture reaches event validation

Status: **correctness repair; not a performance iteration**.
Date: 2026-09-20.

## Failure and root cause

The integration fixture `crates/velnor-workflow/tests/fixtures/check-profiles-workspace`
declares `tools = ["ripgrep"]` for its macOS compatibility check profile but
has no `mise.lock`. Strict generator validation correctly rejects that input
before `an_unknown_event_stops_generation` can exercise the intended
`events = ["release"]` failure. The negative test was therefore invalid under
the new locked-tool contract.

## Repair

The canonical fixture now contains a minimal `mise.lock` generated by Mise
v2026.9.11, pinning `ripgrep` 14.1.1 for `macos-arm64`. `copy_fixture` copies
that lock with the rest of the fixture. The unknown-event test also generates
the valid baseline once before mutating `events`, proving the negative result
is reached from a valid input. This keeps the compat profile's tool declaration
and makes event validation the first relevant failure. It does not weaken lock
validation or event handling.
