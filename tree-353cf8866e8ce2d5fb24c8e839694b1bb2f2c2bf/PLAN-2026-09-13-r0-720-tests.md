## T1: mirror pend test now drives production (differential)

The 720 test built its own `tokio::Mutex` and never touched production
wiring — reverting production to `std` kept it green. Replaced by
`step_log_publisher_contended_push_pends_without_parking_the_executor`,
which drives the real `start_step_log_publisher` under contention on an
explicit current-thread runtime (endpoint-less job, one live chunk, no
feed/results I/O). Passing the mirror to the production function by
value pins the production handle type at compile time.

Differential status: FAILS TO COMPILE against pre-fix production
(E0308 at the call — verified by transplanting the test verbatim onto
the pre-fix tree). At runtime, the 100ms timer firing while the
publisher pends on the held lock proves the push does not park the
executor.

## T2: zombie test sleep replaced by an exit-poll loop (not differential)

`kill_reaps_an_already_exited_child_without_error` slept a fixed 1s,
which can silently cover the live-kill path. Now `wait_for_zombie`
polls `ps` for the `Z` state (10s deadline, loud timeout): only the
observed zombie state proves kill runs against an already-exited child.

Honest status: NOT differential — the entry-present path is unchanged
pre-fix (verified: passes on the parent). It pins kill-after-exit
behavior (Ok, entry dropped, ESRCH proving reap-not-zombie).

## T3: concurrent slow-exit liveness probe added (not differential)

New `kill_and_spawn_stay_live_under_concurrent_slow_exit`: a
slow-exiting child (`sleep 30`, SIGKILLed from a second thread) runs
while the main thread performs a timed 25-cycle spawn/kill burst; every
pid is ESRCH-probed afterwards (no leaked zombies, no stall).

Proof boundary: this is NOT differential against the pre-fix guard
scope, and no timing test can be: `kill` SIGKILLs before `wait`, and no
userspace-arrangeable mechanism delays death from SIGKILL (probed:
vfork parents are TASK_KILLABLE, stopped/traced processes die promptly,
a userns init is unavailable in containers) — so no arrangeable window
exists where the old guard scope would stall a concurrent op. The guard
scope is proven by construction (the `let` binding ends before `wait`);
the no-signal contract is proven by code removal (no signal call exists
on the no-entry path). This test pins live concurrent progress so a
future serialization regression fails loudly.
