# Plan note 2026-09-13 — PR 704 fast-follow corrections (branch `r0-704-corr`)

Base: `origin/main` at `91defe66` (fetch time).

## C1: mirror mutex still blocks a tokio worker

PR 704 shrank the per-chunk critical section but left the mirror behind a
`std::sync::Mutex` locked in the async publisher loop: while the cancel
path holds the lock across its drain, every streamed chunk parks a tokio
worker on a blocking lock.

Fix (`crates/velnor-runner/src/runner.rs`):

- Mirror is now `Arc<tokio::sync::Mutex<StreamedStepLogMirror>>`: creation,
  `start_step_log_publisher` (per-chunk push), `drain_step_publishers`
  (eviction read), and the cancel-path drain all `.lock().await`.
- `take_logs` split into `drain` (mem::take the deque + reset the byte
  gauge under the lock) and `unwrap_drained` (the `try_unwrap`/clone walk
  after unlock). Production takes evicted+drained in one locked scope and
  converts after; `take_logs` survives as a `#[cfg(test)]` shorthand.
- Regression test:
  `streamed_step_log_mirror_push_pends_without_parking_the_executor`
  (current-thread runtime: a blocking mutex would wedge the only thread
  and the contention timeout could never elapse).

## C2: no-entry kill signals a possibly recycled pid

After entry-drop plus reap the pid is free, and the no-entry path signaled
the bare numeric pid — a recycled pid takes a stray SIGTERM. Production
no-entry implies already-reaped-by-us, so the signal is all risk. The map
guard (a temporary in the `if let` scrutinee) also lived across the
blocking `wait()` in both kill and spawn-collision paths, serializing all
kills/spawns behind one child's exit.

Fix (`crates/velnor-runner/src/executor.rs`):

- No-entry path returns Ok without signaling (unknown-to-daemon means
  gone); `signal_spawned_pid` removed. `stop_jailer` retries still
  converge via the owned token.
- Kill and spawn-collision paths bind the map result in a `let` first, so
  the guard drops before the blocking `wait()`.
- New test: `kill_reaps_an_already_exited_child_without_error` (kill an
  exited `sh -c "exit 3"`: Ok, entry dropped, `kill(pid,0)` ⇒ ESRCH
  proving reap-not-zombie). Existing `kill_reaps_…_treats_gone_as_gone`
  reworded to the no-entry-no-signal contract.
