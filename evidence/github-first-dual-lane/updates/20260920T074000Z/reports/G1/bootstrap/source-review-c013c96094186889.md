### G1-BI-2 — trusted source closure is not runtime dependency closure

**P1.** The embedded namespace scanner follows local `uses:` workflow/action graph edges and compares all `.github/**` plus reachable action-root files (`s2/mod.rs:4701-4747,4794-4820,4842-4861,4888-4898`). It does not resolve files executed or read by:

- workflow `working-directory` / environment path inputs;
- composite/JavaScript/Docker action `run` or path inputs; or
- repository-relative shell/script/config references outside `.github` or the reachable action root.

The scanner's own comment at `s2/mod.rs:4924-4933` claims the exact action closure covers shell behavior; it does not.

Exact scanner reproduction from the embedded body (not a reimplementation): base and head tar archives had identical `.github/workflows/ci-pr.yml` containing a fixed candidate uploader and `run: bash scripts/publish.sh`; `scripts/publish.sh` differed only between base/head.
