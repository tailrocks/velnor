Likewise, `local_workflow_pattern` only follows `./.github/workflows/...` paths (`s2/mod.rs:4653-4706`). A reachable job-level external reusable workflow (`owner/repo/.github/workflows/publish.yml@<sha>`) is not traversed; its hidden upload surface and input-provided candidate namespace are invisible to this census. Direct API uploads in `run:` are also outside the recognized action surface. The existing fixture covers named extra/dynamic direct uploaders, not these forms.
