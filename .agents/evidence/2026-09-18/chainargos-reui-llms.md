# ReUI

> ReUI is a first-class shadcn registry: 22 custom primitives and 1,105 free component examples, plus 543 premium blocks across 6 groups and 638 icons in 4 styles. Built for React and Tailwind CSS v4, shipped as source you own, with every component available in both Base UI and Radix UI. A hosted MCP server lets coding agents search and install from the registry directly.

## MCP and Agent Skills

ReUI ships a hosted MCP server so coding agents install real components instead of hallucinating APIs.

- Endpoint: https://mcp.reui.io (Streamable HTTP)
- Access: free with a ReUI account. Your agent opens a "Sign in with ReUI" approval on first connect, and a free account is created in that flow. Headless and CI runs use a personal token from your ReUI account instead.
- Tools: 19, covering scored search, component APIs, page composition, prop validation and exact install commands.
- What is free: components and examples. Premium blocks and icons install with a Pro or Ultimate license, and passing that license key as the MCP credential is also what makes them visible in search results.
- Limits: a free account has a daily request allowance that resets at UTC midnight; Pro and Ultimate licenses are uncapped by default.
- [MCP overview](https://reui.io/mcp): What the MCP server does and how to connect.
- [MCP docs](https://reui.io/docs/mcp): Setup, tools, and troubleshooting.
- [Agent skills](https://reui.io/docs/agent-skills): The workflow the agent follows: search, read the real API, install, then self-audit.
