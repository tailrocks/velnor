So ChainArgos missed the fix by ~1 hour. The defect is **old pin**, not a
missing declaration: with the pre-`2678913a` renderer the local-path `uses:`
was an unconditional const — even a declared `[generator] revision` would
still have emitted the same broken local ref (the const took no revision).
The missing `revision` key is a separate provenance gap (C-ca-3) that matters
for the FIX, not the cause: the fixed renderer needs `workflow_revision` to
interpolate the remote `@<pin>`, and the policy validator needs the declared
pin to reproduce the tree.

### 3.2 How the action bytes reach each repo today (current source)

- `builtin_generated_actions()` (`lib.rs:4987`) returns an **empty map** —
  the generator emits zero local action files for anyone, by design.
- Owner (`tailrocks/velnor`) gets its action dir via explicit
  `[[static_files]]` in its own `.github-gen/velnor-workflow.toml:294-296`
  (`.github-gen/sources/actions/…` → `.github/actions/…`), plus the local
  `uses:` path. A test pins the copy byte-identical to the source template
  (`lib.rs:10680`).
- Consumers get the **remote pin** and no local dir. Enforced by
  `crates/velnor-workflow/tests/velnor_first_ci.rs:958`:
  "consumer kind reusables must reference the published report action".
- `validate_workflow_revision` (`lib.rs:2631`) fails generation unless
  `workflow_revision` is a full 40-char SHA — G1 must declare the pin.

### 3.3 Root-cause class (why the architecture allowed it)

The file emitter (`builtin_generated_actions`) and the reference renderer
(`ir.rs` report step) were changed in **separate commits 14h apart** with no
single test asserting their consistency for consumers ("every emitted `uses:`
resolves to an emitted file or a remote pin"). The window between them
produced self-inconsistent trees. The `2678913a` fix removes the enabling
condition structurally (consumers never reference local files), and
`velnor_first_ci.rs:958` now pins the consumer shape — no new test needed
for G1 beyond running the existing suite at the G-gate pin.
