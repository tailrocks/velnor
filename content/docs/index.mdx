# Velnor

Velnor is a Linux GitHub Actions control plane with two local execution lanes.
The native lane uses Velnor runner slots and an explicitly selected Docker or
Firecracker microVM backend. The optional Scale Set lane runs an official
one-job Actions runner container with its own private Docker-in-Docker (DinD)
daemon. Both lanes share one host-wide permit ledger; GitHub remains the
scheduler and source of truth.

Velnor supplies registration, admission, lifecycle supervision, execution,
and bounded local operational state.

Velnor is a research project. Expect breaking changes. Current documentation
describes implemented behavior; it is not a production-readiness claim.

## Current boundaries

- The packaged runtime targets Debian hosts and systemd.
- The native lane selects Docker or microVM explicitly; neither falls back to
  the other. The optional Scale Set lane uses its official runner and private
  DinD worker profile.
- Native action and capability admission is strict and cannot be bypassed.
  Scale Set offer classification uses the event plus owner and repository:
  unparseable events, missing owner/repository, `pull_request`-family events,
  and `workflow_run` stay `unknown`; other parseable events with both nonempty
  owner and repository fields are `trusted`.
- Native registration uses an operator PAT; Scale Set administration uses a
  separately configured GitHub App or PAT reference. Native job credentials
  come from the acquired GitHub payload; Scale Set job credentials come through
  the official runner's GitHub session. Neither admin credential replaces job
  credentials.
- The control socket exposes reads, events, logs, and telemetry. Lifecycle
  mutation routes, reconciliation actions, and diagnostics bundles are not
  currently available through the public control interface.
- Local query and log projections are bounded and some projections are not
  rebuilt after reopening the service. Treat GitHub as authoritative for job
  state and use local events, files, and service logs as operational evidence.
